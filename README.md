# Phoenix Evidence Chat

צ׳אט בעברית המפיק תשובות מתוך קטעים שנאספו מהאתר הציבורי של הפניקס, עם קישורים וציטוטים שניתן לבדוק. פרויקט הדגמה עצמאי להאקתון, ללא שיוך רשמי להפניקס.

## מה המערכת עושה

סריקה של עמודים ציבוריים → ניקוי תוכן → חלוקה לקטעים עם כתובת ותאריך → הטמעות → אחזור משולב של דמיון סמנטי וחיפוש מילים → ניסוח תשובה → בדיקת תמיכה במקורות → הצגת תשובה ומקורות, או הודעה שאין מספיק מידע.

Python 3.12, Flask, JavaScript רגיל, BM25L, OpenAI embeddings, SQLite ו־NumPy לחיפוש וקטורי מדויק. מודל המענה מוגדר ב־answering.py. בחירה ב־SQLite/NumPy החליפה את Chroma בעקבות קריסת ספריית האחסון ב־Windows. לא נדרשת הורדת מודל מקומי.

## הפעלה מקומית ב־Windows

מתיקיית הפרויקט:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
$phoenixKey = Read-Host "OpenAI API key" -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', $phoenixKey).Password
Remove-Variable phoenixKey
```

אם קיים כבר אינדקס סמנטי פעיל ב־data/index, אין לבנות אותו מחדש. בעותק ההגשה המיוצא יש אינדקס מוכן ב־demo_index. להפעלתו מקומית בלי API לבניית אינדקס:

```powershell
.venv\Scripts\python -c "from cloud_start import prepare_index; prepare_index('demo_index','data/index')"
.venv\Scripts\python app.py
```

פתחו http://127.0.0.1:5000 . שאלה חדשה ושאלת המשך משתמשות ב־API בתשלום. אין להעלות מפתח למאגר או לשלוח אותו בצ׳אט. ללא מפתח אפשר להריץ בדיקות מדומות, אך לא לקבל תשובות מהמודל.

## הפיצ׳ר הנוסף: למה זו התשובה?

מתחת לכל חלק בתשובה אפשר לפתוח את הציטוט המדויק שמבסס אותו, בנוסף לקישור לעמוד והצגת קטע המקור. המודל בוחר מזהי קטעים מתוך המקור; השרת מחלץ את הטקסט בעצמו ובודק אותו. ביקורת מודל נפרדת בודקת שהטענה נובעת מהמקור ושומרת על התנאים. במקרה דחייה אפשר ניסיון תיקון תוכן אחד; אם גם הוא נדחה, התשובה אינה מתפרסמת. בדיקות אלה מצמצמות סיכון ואינן מבטיחות נכונות מוחלטת.

## בדיקות

בדיקות קוד, ללא קריאות API:

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
node --test tests/chat-ui.test.cjs tests/source-links.test.cjs
```

בדיקות HTTP וחיפוש משתמשות במאגר מילולי זמני ונפרד מהאינדקס הפעיל. הן אינן בונות מחדש את אינדקס ההדגמה.

24 מקרי בדיקת שיחה נמצאים ב־evaluation/chat_cases.json. הרצה מרוכזת מול השרת המקומי הפועל:

```powershell
.venv\Scripts\python run_chat_checks.py
.venv\Scripts\python run_chat_checks.py --execute
```

הפקודה הראשונה היא תצוגה מקדימה ללא תשלום. השנייה שולחת בקשות בתשלום, בזו אחר זו. נכתבים evaluation/chat-run.json ו־evaluation/chat-run.html אחרי כל תשובה. אין ציון נכונות אוטומטי: יש לקרוא את התשובות מול המקורות והקריטריונים. תקלה עוצרת את הריצה ללא ניסיון חוזר. קובצי התוצאות אינם נשלחים לגיט כברירת מחדל. כ־20 תרחישים נוסו במערכת המקומית לאורך כמה גרסאות. ברובם התקבל מענה מתאים למקורות; תועדו גם חסימות, חזרתיות וניסוחים לא ממוקדים. אין כאן טענה שכל התרחישים עברו באותה גרסה סופית. בקשות מפורשות להמצאת פרטי קשר ולהבטחת אישור תביעה מקבלות כעת הודעת מגבלה מקומית; הטיפול הזה נבדק בקוד ועדיין דורש אימות במערכת הסופית.

## כיסוי ומגבלות

דגימת הבדיקות המקורית כוללת שישה עמודים שנאספו ב־15.10.2026 ו־178 קטעים. כיסוי האינדקס המיוצא בפועל מופיע בקובץ INDEX_COVERAGE.json ובממשק; הוא עשוי להיות רחב יותר לאחר סריקה ובניית אינדקס חדש. אין להסיק מכך שכל האתר נכלל. אותרו קישורי PDF, אך תוכן המסמכים לא פוענח. אי־מציאת מידע במאגר החלקי אינה הוכחה שאין מידע כזה באתר כולו. אין גישה לנתוני לקוח, בדיקת פוליסה אישית או ביצוע פעולות. היסטוריית עד שלושה סבבים נשמרת בזיכרון הדף ונמחקת ברענון או בשיחה חדשה. שאלות והקשר נשלחים לספק המודל; אין להזין פרטים אישיים.

## עלויות וענן

בניית האינדקס והשאלות משתמשות ב־API בתשלום. מכסת שכבת המענה המקומית היא 2 דולר לפי המחירים המתועדים בקוד; להטמעות מכסה נפרדת. אלה אינן מגבלות לכל חשבון ה־API. לא מוחקים קובצי שימוש כדי לעקוף מכסה. פריסה בחינם ב־Render מאבדת נתוני שימוש בעת אתחול/שינה ולכן אינה שומרת מכסה מצטברת בין אתחולים. פריסה עם דיסק קבוע ושמירת PHOENIX_INDEX_ROOT עליו משמרת את הרישום. לפרטי פריסה וכניסה לדמו: DEPLOY_HE.md.

## רענון תוכן

אין רענון מתוזמן. מפעילים crawler.py מחדש, בודקים את איכות הסריקה ואז בונים דור אינדקס חדש. רק דור שהושלם מסומן כפעיל. לדוגמה:

```powershell
.venv\Scripts\python crawler.py --max-pages 6
.venv\Scripts\python ingest.py data/crawls/NEW_RUN/pages.jsonl --mode semantic
```

מחליפים NEW_RUN בשם ההרצה החדשה. הפקודה האחרונה מעריכה עלות בלבד; מוסיפים --execute רק אחרי בדיקת הכיסוי והאומדן, כדי להפעיל הטמעות בתשלום. הגדלת היקף דורשת התאמת תקרת הבקשות בקובץ crawl_config.json ובדיקת סוגי עמוד נוספים. אין צורך ברענון או בניית הטמעות לצורך עדכון תצוגה בלבד.

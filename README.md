# הפי — עוזר חכם למידע מאתר הפניקס

צ׳אט בעברית שמחפש במידע שנאסף מהאתר הציבורי של הפניקס, מנסח תשובות עם מקורות ומציג את הציטוטים שעליהם הן מבוססות. נבנה כהדגמה עצמאית במסגרת האקתון; אינו שירות רשמי של הפניקס.

**[פתיחת המערכת](https://phoenix-ai-assistant.onrender.com) · [קוד המקור](https://github.com/RIVKI-SHVARTS/phoenix-ai-assistant)**

הדמו מוגן בסיסמת כניסה: שם המשתמש הוא `demo`, והסיסמה נמסרת לבודקות בנפרד. אין לפרסם סיסמאות או מפתחות API במאגר.

## מה אפשר לעשות

- לשאול בעברית על מידע כללי במקורות שנאספו: תביעות, ביטוחי דירה ורכב, נסיעות לחו״ל, בריאות, חיסכון, פנסיה ונושאים נוספים.
- לקבל תשובה עם הפניות לעמודי המקור ותאריך איסוף המידע.
- לפתוח את **„למה זו התשובה?”** ולקרוא את הציטוטים התומכים בכל חלק בתשובה.
- להמשיך בשאלות מתוך הקשר השיחה או לפתוח שיחה חדשה.
- לשלוח שאלה באמצעות Enter; מעבר שורה באמצעות Shift+Enter.

כאשר אין מידע מספיק, המערכת אמורה לציין זאת. היא אינה מתחברת לפוליסה האישית, אינה בודקת מצב תביעה ואינה מבצעת פעולות עבור לקוח.

הנתונים מתועדים ב־[INDEX_COVERAGE.json](INDEX_COVERAGE.json). זהו מאגר מורחב שהחליף את דגימת הפיתוח הראשונית; **אין כאן טענה לכיסוי מלא של האתר**. חלק מהעמודים לא נכללו עקב כשלים בסריקה, כפילויות או צורך בבדיקה נוספת. קישורים למסמכי PDF עשויים להופיע במקורות, אך תוכן המסמכים עצמם לא פוענח.

המענה מבוסס על עותק שנאסף מהאתר, ולא על גלישה חיה בכל שאלה. תאריך האיסוף של כל מקור מוצג בממשק.

## איך המערכת עובדת

1. **איסוף והכנה:** סריקת עמודים ציבוריים, חילוץ תוכן וחלוקה לקטעים עם כותרות, כתובת מקור ותאריך איסוף.
2. **אינדוקס:** יצירת הטמעות ושמירתן לצד הקטעים. האינדקס המוכן כלול בתיקיית `demo_index`, ולכן אין צורך לייצר אותו מחדש לצורך התקנה או פריסה.
3. **חיפוש משולב:** חיפוש לפי מילים באמצעות BM25L וחיפוש סמנטי באמצעות דמיון וקטורי. הדירוגים משולבים כדי לבחור מקורות לשאלה.
4. **ניסוח מבוסס מקורות:** המודל מקבל את הקטעים שנבחרו ומחזיר טענות עם מזהי ציטוטים. השרת מחלץ את הציטוטים מתוך המקור השמור ובודק את ההפניות.
5. **ביקורת לפני הצגה:** קריאת מודל נפרדת בוחנת אם הטענות נתמכות במקורות ושומרות על התנאים וההסתייגויות. בדחייה מתאפשר ניסיון תיקון אחד; אם התשובה עדיין אינה עוברת את הבדיקה, היא אינה מוצגת כתשובה מאומתת.

בשאלת המשך, המערכת משתמשת בהיסטוריה כדי לפתור את ההקשר לפני החיפוש. ההיסטוריה אינה משמשת מקור עובדתי. הבדיקות מצמצמות סיכון לטעויות, אך אינן מבטיחות נכונות מוחלטת.

## כלים וארכיטקטורה

| שכבה | מימוש |
| --- | --- |
| ממשק | HTML, CSS ו־JavaScript, עברית ו־RTL |
| שרת | Python 3.12 ו־Flask |
| חיפוש מילולי | BM25L |
| חיפוש סמנטי | SQLite ו־NumPy, חישוב דמיון מדויק |
| הטמעות | OpenAI `text-embedding-3-large` |
| ניסוח וביקורת | OpenAI Responses API, מודל `gpt-5.4-mini-2026-03-17` |
| פריסה | Render ו־Gunicorn |

הבחירה ב־SQLite ו־NumPy מאפשרת אחסון מקומי ללא שירות מסד וקטורי חיצוני וללא הורדת מודל מקומי. בהפעלה בענן מורכבים חלקי האינדקס ונבדקים גודל הקבצים, חתימות SHA-256 ומספרי הקטעים והווקטורים לפני הפעלת המאגר.

## הפיצ׳ר המקורי: „למה זו התשובה?”

לצד כל חלק בתשובה ניתן לפתוח את הציטוט המדויק שעליו הוא מבוסס. המשתמש יכול לבחון את הבסיס לתשובה בלי לחפש אותו בעמוד שלם — במיוחד כשדרישה תלויה בסוג האירוע או בתנאי הפוליסה.

**איך מנסים:** שואלים „האם בכל תביעה על נזק בדירה חייבים לצרף גם אישור משטרה וגם אישור מכבי אש?”, ואז פותחים „למה זו התשובה? הצגת הציטוטים”. בודקים שההבחנה בתשובה תואמת את התנאים במקור.

## הפעלה מקומית ב־Windows

פתחו PowerShell בשורש הפרויקט, ליד `app.py`:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

הגדירו מפתח API בחלון שבו יופעל השרת:

```powershell
$phoenixKey = Read-Host "OpenAI API key" -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', $phoenixKey).Password
Remove-Variable phoenixKey
```

הכינו את האינדקס המצורף והפעילו את השרת:

```powershell
.\.venv\Scripts\python.exe -c "from cloud_start import prepare_index; prepare_index('demo_index', 'data/index')"
.\.venv\Scripts\python.exe app.py
```

פתחו [http://127.0.0.1:5000](http://127.0.0.1:5000). הכנת האינדקס המצורף אינה שולחת בקשות הטמעה. חיפוש סמנטי ושיחה עם המודל משתמשים ב־API בתשלום. אם כבר קיים אינדקס מקומי פעיל, בדקו את הדור הפעיל לפני החלפתו באינדקס המצורף.

## פריסה בענן

הגדרות השירות בקוד:

| הגדרה | ערך |
| --- | --- |
| Build Command | `pip install -r requirements-cloud.txt` |
| Start Command | `python cloud_start.py` |
| Health Check Path | `/healthz` |
| `PYTHON_VERSION` | `3.12.8` |
| `PHOENIX_INDEX_ROOT` | `runtime/index` |
| `OPENAI_API_KEY` | מפתח פרטי בהגדרות השירות |
| `DEMO_PASSWORD` | סיסמת דמו פרטית בהגדרות השירות |

אין ליצור הטמעות מחדש בזמן הפריסה. הוראות נוספות נמצאות ב־[DEPLOY_HE.md](DEPLOY_HE.md).

`/healthz` בודק שהשרת מגיב. `/api/health` מציג את מצב האינדקס, מספר העמודים והקטעים ומוכנות הגדרות השיחה; הוא **אינו בדיקה מלאה של קבלת תשובה מהמודל**. אחרי פריסה יש לבדוק גם שאלה ותשובה בפועל.

## בדיקות

בדיקות הקוד משתמשות בתגובות מודל מדומות ובנתוני בדיקה; הן אינן מפעילות את שירות המודל בתשלום:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/chat-ui.test.cjs tests/source-links.test.cjs
```

לבדיקות שיחה מול שרת מקומי פועל:

```powershell
.\.venv\Scripts\python.exe run_chat_checks.py
.\.venv\Scripts\python.exe run_chat_checks.py --execute
```

הפקודה הראשונה מציגה תוכנית בלבד. `--execute` שולח בקשות בתשלום ושומר תוצאות לבדיקה. ההרצה אינה מעניקה ציון נכונות אוטומטי: צריך לקרוא את התשובות מול המקורות. הצלחת בדיקות הקוד אינה הוכחה שכל שאלות המשתמש יקבלו תשובה נכונה בענן.

דוגמאות לבדיקה ידנית:

- „אילו מסמכים צריך לצרף לתביעה על נזק בדירה?”
- „פרצו לי לבית ולקחו חפצים. מה צריך לעשות קודם?” ולאחריה „ואיזה אישור צריך להעביר?”
- „כמה זמן לפני הנסיעה אפשר לרכוש ביטוח נסיעות לחו״ל?”
- „מה מצב התביעה שלי מספר 12345?” — מצופה הסבר שאין גישה לנתוני תביעה אישית.
- „איך משנים סיסמה לחשבון נטפליקס?” — מצופה הימנעות ממענה שאינו מבוסס על המאגר.

## מגבלות ותפעול

- אין גישה לפוליסות אישיות, למידע פנימי או לביצוע פעולות. מידע כללי אינו אישור לכיסוי במקרה אישי.
- שאלות והקשר השיחה נשלחים לספק המודל. אין להזין פרטים אישיים או מסמכים פרטיים.
- הקשר השיחה נשמר בזיכרון הדף, עד שלושה סבבים, ונמחק ברענון או בפתיחת שיחה חדשה.
- אין רענון תוכן אוטומטי. עדכון המידע דורש סריקה, בדיקת תוצאות ובניית דור אינדקס חדש. שינוי עיצוב אינו דורש בניית אינדקס.
- חיפוש, ניסוח וביקורת הם שלבים נפרדים, ולכן זמן התשובה אינו מיידי. ייתכן גם ניסיון תיקון נוסף. בשירות הענן החינמי תיתכן המתנה להתעוררות לאחר חוסר פעילות.
- קיימים רישומי שימוש ומכסות מקומיות בקוד; הם אינם תקרת הוצאה כוללת של חשבון OpenAI. אחסון זמני בענן אינו מבטיח שמירת רישומי השימוש בין אתחולים.
- אין להעלות לגיט מפתחות, קובצי `.env`, סביבת `.venv`, רישומי שימוש או תוצאות שיחות פרטיות.
